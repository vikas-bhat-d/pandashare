
**Prompt:**

Create a minimal flat vector logo for a project called “PandaShare”.
It is a zero-knowledge encrypted file sharing platform.
The logo should feel like an open-source project logo — clean, modern, simple, not corporate.

Style requirements:

* Flat vector style
* Minimal shapes
* 2–3 colors maximum
* No heavy gradients
* Works well as favicon and GitHub project logo
* Modern sans-serif typography

Visual concept:

* Include a cute but minimal panda illustration.
* The panda should be simple, geometric, and not overly cartoonish.
* Integrate the panda creatively with the text “PandaShare”.
* Subtly reflect privacy or encryption without using aggressive lock icons. Keep it subtle and clean.
* For example, the panda face could be inside the letter “P”, or ears peeking above the first letter, or the panda subtly holding a small file or lock icon.


Color palette:

* Black and white panda
* Soft gray
* Optional subtle accent (light green or soft blue)

The final design should feel friendly, privacy-focused, and open-source inspired.
